Pose Based Game Controller

👇 Watch me play snake and subway surfer using a pose-based controller I built with Python, OpenCV, MediaPipe, and PyAutoGUI. The controller maps body movements to in-game actions and works for any game that uses the mapped controls. Practical challenges included:

  • 🎥 Finding poses that the camera could see clearly without stepping too far from the screen
  • ⌨️ Preventing repeated key presses (so it didn’t “hammer” inputs)
  • 🎬 Adding logic to start, pause, and resume the control

Retrieval Augmented Generation

I spent a few months experimenting with RAG (Retrieval Augmented Generation).

  • 💰 I spent $ 0.18 to create embeddings and complete LLM calls while testing 4 embedding models (I used 2 models by OpenAI). It's cheap!
  • 📈 I compared 4 embedding models and found 3 of the 4 models to have comparable results with HuggingFace's Sentence Transformers all-mpnet-base-v2 having a slight edge.
  • 📓 Chat history greatly improves user experience with a chat agent but negatively impacted the results when processing unrelated test cases.
  • 🚫 RAG doesn’t analyze documents to find insights and enable summarization. It provides additional context by retrieving results similar to the question - so manage your expectations!
  • 🤓 Nerds, you can see all the details of my pipeline and evaluation in a Jupyter Notebook on github.

Personal Assistant is the base project for the RAG solution. It is single page app built using OpenAI gpt-4o-mini model. JavaScript calls API endpoints in the Python Flask backend. Flask sessions are used to maintain conversation history. There is a function to clean up stale sessions.

Umbrella App

Heading out? Wondering if you should bring an umbrella? This app will keep you dry.

I used Virtual crossing weather API to retrieve the chance of rain, and Twilio API to send the SMS message that lets you know whether you need an umbrella. The background image was ai generated by ChatGPT 4o.

This Python Flask app is an adaptation of the rain tracker project in Angela Yu's 100 Days of Code: The Complete Python Pro Bootcamp.
